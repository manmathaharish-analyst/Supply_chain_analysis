# Supply Chain Analysis Dashboard

## Project Overview
This project analyzes supply chain operations to identify inventory trends, logistics costs, shipment performance, and operational efficiency using Power BI.

## Tools Used
- Power BI
- Microsoft Excel

## Key Insights
- Kolkata has the highest inventory level.
- Logistics costs impact profitability.
- Inspection delays affect operational efficiency.
- Inventory distribution varies across locations.

## Dashboard Features
- Executive Summary
- Inventory Analysis
- Logistics Cost Analysis
- Interactive Filters
